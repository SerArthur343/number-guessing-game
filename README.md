# number-guessing-game
A simple number guessing game developed with C# and .NET.

## Features
- Random number generation (1-100)
- Higher/lower hints
- Wrong guess counter
- Replay option

## Technologies
- C#
- .NET

## How to Play
1. Run the application.
2. Guess a number between 1 and 100.
3. Follow the hints to find the correct number.
4. Choose whether to play again.
